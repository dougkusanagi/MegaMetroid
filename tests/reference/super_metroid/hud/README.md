# Referência visual do HUD

`hud_tanques_brinstar.png` (960×720, 4:3 esticado): captura do HUD do Super Metroid
original fornecida pelo usuário em 04/11/2026, mais adiante no jogo (Brinstar),
com 5 tanques de energia, energia 39, mísseis 100, supers 04, power bombs 18,
grapple, X-ray, seletor AUTO e mini-mapa. Uso: conferir posição, cor e espaçamento
dos quadrados dos tanques e dos itens que ainda não existem no porte.

Limites: a imagem foi redimensionada e não é pixel a pixel. Não é uma medição de
RAM nem prova de comportamento. No começo do jogo a Samus tem 99 de energia e
nenhum tanque, por isso o HUD do porte ainda não mostra quadrados.
